## 5. 换电脑 / 新会话怎么接

1. 克隆仓库（含 `docs/` 镜像与 `tools/continuity/`）。
2. 打开项目 → 自检任务自动跑 `install-global-instruction.ps1`，本机用户级指令缺失即补装。
3. **首次回灌记忆前**：先把 `docs/项目记忆.md` 内容并入本机 Copilot 记忆，再运行 `sync-memory.ps1`（防稀疏记忆覆盖完整镜像；误覆盖可从 git 历史找回）。
4. 继续按「每轮收尾」执行。

## 7. 移植蓝本：CUI（C 版，已确认为蓝本）

- 位置 `G:\Code\C\CUI`（上游 `yappologistic/CUI`，**MIT**，本地 `master` = `e8688b8`）；C99 **立即模式** UI 库，自述约 190 个组件，自带软件 + OpenGL 渲染器，后端 Win32 / Cocoa / X11 / SDL2 / GLFW。
- 规模（实测）：`src/*.c` **61 个文件 52,290 行**；`include/*.h` 4 个 3,708 行（`cui.h` 单文件 241 KB）；`third_party` 577 KB（stb 系列）。
- **体积基线（本机实测 2026-11-10）**：`examples/hello.exe` = **303,104 B（296.0 KB）**，`zig cc` + CMake/Ninja、`-Os -DNDEBUG -Wl,--gc-sections -mwindows`、MinSizeRel、**无 LTO**；`libcui.a` = 2,117 KB。
- 上游体积纪律（`docs/architecture.md:158`）：改核心代码要量 `examples/hello` 在 `MinSizeRel` 下的增量；核心**不直接调用组件文件**（Windows 链接器按文件保留），可选功能由组件自己装 hook。
- 版权：MIT，移植需保留上游 `LICENSE` 与版权声明；不直接按文件「翻译」，按模块重写并在 `docs/` 登记对照关系。

## 8. 多平台架构（用户硬性要求）

- **分层**：`types / core / render / widgets / theme` 完全平台无关；`platform.zig` 是唯一平台入口，联合体成员 = `win32` / `null_backend`，后续加 `cocoa` / `x11`。
- **新增平台步骤**：新建 `src/platform/<name>.zig`，实现 `init / deinit / poll / size / scale / pixels / present / measure`；在 `platform.Backend` 加一个联合成员与转发分支；`App.init` 里选择后端。
- **当前实测范围**：Win32（x64 / x86）已构建并冒烟；Cocoa / X11 **未实现**，本机无验证环境，不得写成「已支持」。
- **文本渲染**：里程碑 1 由平台层用系统字体画（Win32 GDI），核心只发 `text` 绘制指令；好处是不内嵌字体、体积小。是否改成「核心自带 TTF 光栅 + 内嵌字体」待定，切换时只动 `render`/`platform`。
