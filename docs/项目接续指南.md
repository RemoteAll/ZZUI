## 5. 换电脑 / 新会话怎么接

1. 克隆仓库（含 `docs/` 镜像与 `tools/continuity/`）。
2. 打开项目 → 自检任务自动跑 `install-global-instruction.ps1`，本机用户级指令缺失即补装。
3. **首次回灌记忆前**：先把 `docs/项目记忆.md` 内容并入本机 Copilot 记忆，再运行 `sync-memory.ps1`（防稀疏记忆覆盖完整镜像；误覆盖可从 git 历史找回）。
4. 继续按「每轮收尾」执行。

## 6. 每轮收尾（务必）

① `docs/决策记录.md` 新增一节（**含用户原话**）；② 运行 `tools/continuity/sync-memory.ps1` 同步记忆；③ 跑 `tools/regression.ps1` 并如实汇报；④ 提交（有远端则推送）。
